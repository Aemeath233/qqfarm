# 个人农场网页控制台

使用浏览器管理设置，Python 程序维护农场连接和自动种收。本机运行时打开 `http://127.0.0.1:8790`；也可以在服务器运行，通过 SSH 隧道或自己的 HTTPS 域名访问。

## 首次授权

1. 在本机 Fiddler 开启 HTTPS 解密，打开自己的 QQ 农场小程序并等待登录成功。
2. 关闭小程序后导出 SAZ。确保归档包含最新一次完整成功登录，SAZ 最大 40 MiB。
3. 登录面板，点“导入 Fiddler SAZ”。程序核对登录时间不超过 5 分钟，解析临时授权并连接农场、确认心跳。
4. 登录成功后手动点“开始挂机”。导入授权不会自动开启游戏写操作。

上传的 SAZ 只在请求期间解析，不存入数据目录或操作日志。程序加密保存所需农场会话；这不是完整 QQ Cookie 或 QQ 登录。请只向自己的本机面板或 HTTPS 面板上传自己的 SAZ。

Fiddler 是独立研究工具，不集成进网页或服务器。日常运行只上传 SAZ 授权文件，不上传完整流量分析文件。

## 页面设置

- **农场概览**：查看账号、金币、地块和成熟倒计时。浏览器轮询读取服务器缓存。
- **种植计划**：文字列表选种；优先级可直接移除和上下调整。默认按现有金币购种，也可选择只用库存或限制预算；白萝卜回退在挂机设置中调整。
- **好友互动**：先查看今日排行，按成功互动的地块次数统计；分开设置帮助、采摘、放虫、放草及频率。
- **我的仓库**：逐条显示游戏背包 UID 记录。未知物品不会仅凭名称或基础价格自动标记为可售。
- **任务奖励**：查看任务并领取已完成的奖励；自动领取默认关闭。
- **挂机设置**：配置照料、施肥、出售和查询频率。开始按钮显式启用自动操作。
- **运行记录**：查看最近 7 天结果。未确认的写操作不会自动重发。

## 授权和重启

Fiddler SAZ 中必须有最近 5 分钟内成功的农场登录；导出文件时间不等于登录时间。SAZ 过期、登录失败或授权失效时请重新抓取成功登录再上传。服务重启会结束内存里的农场连接，需要重新授权并手动开始。

本机运行数据默认在 `data/server/`。Ubuntu 后台服务的数据在 `/var/lib/qqfarm`，配置在 `/etc/qqfarm/qqfarm.env`。安装及可选远程访问说明见 [部署说明](网页部署说明.md)。

## 当前版本

网页可直接上传 Fiddler SAZ，由服务端解析登录帧并完成授权。种植优先级支持直接移除；设置按左右两栏显示，成熟后检查延迟默认 60 秒。邮件查询和领取功能已移除。实际运行的既有自定义设置保留。

0.6.2 对好友拒绝和照料回包不完整增加一次状态复查。详细变更见 [更新记录](changes.md)。自动操作需要程序持续运行；有服务器时推荐安装为后台服务，本机使用请保持电脑开机、联网且不休眠。
