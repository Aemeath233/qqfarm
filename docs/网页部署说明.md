# 部署说明

## 本机运行

Windows、Linux 都可以运行同一套程序。在项目目录执行：

```bash
uv sync --locked --no-dev
uv run --locked --no-dev qqfarm-web
```

打开 <http://127.0.0.1:8790>，管理密码在 `data/server/initial-password.txt`。导入新鲜的 Fiddler SAZ，再手动开始挂机。**本机使用不需要反代或域名。**

## Ubuntu 后台运行（可选）

以下安装脚本适用于 Ubuntu 24.04，需要系统 Python 3.12 和 uv。它会安装并启动 `qqfarm-web` 服务，设置开机启动。

先按照 README 克隆项目并生成部署包：

```bash
uv run --locked --no-dev python scripts/package_server.py
```

在服务器安装系统依赖，将部署包解压到 `/opt/qqfarm`：

```bash
sudo apt update
sudo apt install -y python3 python3-venv unzip
sudo mkdir -p /opt
sudo unzip dist/qqfarm-web-0.6.1-server.zip -d /opt
cd /opt/qqfarm
sudo env PATH="$PATH" bash deploy/install_ubuntu.sh
```

如果在另一台电脑打包，先把 zip 传到服务器，上面的解压路径替换成实际文件路径。首次安装使用空的 `/opt/qqfarm` 目录。

| 内容 | 位置 |
| --- | --- |
| 程序 | `/opt/qqfarm` |
| 配置 | `/etc/qqfarm/qqfarm.env` |
| 持久数据 | `/var/lib/qqfarm` |
| 首次密码 | `/var/lib/qqfarm/initial-password.txt` |

```bash
sudo cat /var/lib/qqfarm/initial-password.txt
sudo systemctl status qqfarm-web
sudo journalctl -u qqfarm-web -n 50 --no-pager
```

## 远程访问

不想配置反代时，在自己电脑开启 SSH 隧道：

```bash
ssh -N -L 8790:127.0.0.1:8790 用户名@服务器地址
```

打开 <http://127.0.0.1:8790> 即可。使用隧道时不设置 `FARM_PUBLIC_URL`，让程序按当前访问地址校验来源。

如果选择公网域名访问：

1. 配置域名和 HTTPS 证书。
2. 在 `/etc/qqfarm/qqfarm.env` 设置 `FARM_PUBLIC_URL=https://你的域名`，不带末尾斜杠。
3. 使用 [Nginx/OpenResty 示例](../deploy/nginx-location.conf.example) 转发到 `127.0.0.1:8790`。上传大小至少 42 MiB，读取超时 150 秒。
4. 重载反代，并执行 `sudo systemctl restart qqfarm-web`。

不要直接通过公网 HTTP 登录或上传授权，程序会拒绝这类请求。跨机器反代还需设置监听地址和 `FARM_TRUSTED_PROXIES`，填写可信反代的实际内网 IP。

## 更新与备份

- **本机**：停止程序，执行 `git pull`、`uv sync --locked --no-dev`，再启动。保留 `data/server/`。
- **Ubuntu**：先停止 `qqfarm-web`，备份 `/var/lib/qqfarm` 和 `/etc/qqfarm/qqfarm.env`；更新 `/opt/qqfarm` 中的程序后，重新运行安装脚本。保留旧程序包，以便回退。
- **只备份数据**：先停止程序，再复制整个数据目录，包含数据库、设置和会话密钥。备份里有授权信息，不要上传到公开仓库。

程序重启会断开农场连接；重新导入 SAZ 后，手动开始挂机。`FARM_ADMIN_PASSWORD` 只在首次初始化时生效，修改它不会覆盖已有管理密码。
